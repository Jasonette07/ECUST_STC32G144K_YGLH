# ECUST_STC32G144K_YGLH

面向“雁过留痕”室内 PVC 赛道竞速项目的 STC32G144K 四轮车模参赛代码。

本仓库保存完整的 Keil C251 工程、赛道图像处理代码、运动控制算法以及 STC32G144K 配套底层库。项目以单摄像头完成赛道检测，并预留环岛、十字路口、目标识别和紫外激光打靶等赛题功能。

## 项目概览

- **主控**：STC32G144K 系列（工程目标：`stc32g144k246`）
- **开发环境**：Keil MDK / C251
- **系统时钟**：96 MHz
- **视觉传感器**：MT9V03X 摄像头
- **运动执行**：舵机转向、DRV8701 电机驱动、编码器测速
- **姿态辅助**：IMU660RA 陀螺仪
- **赛题执行器**：左 / 中 / 右三路激光控制
- **通信与调试**：无线串口、调试串口、蜂鸣器

## 赛题背景

根据本项目对应的比赛说明，车模需要在室内 PVC 赛道上完成一周运行。赛道包含直道、弯道、十字路口、环岛、坡道及砖红色障碍等元素；部分路段设置紫外感光纸和圆形目标区域，车模需要使用紫外激光在目标区域内留下痕迹，并避免在区域外留下痕迹。比赛规则要求仅使用一个摄像头进行赛道检测，不使用额外光电管检测赛道或感光纸。

具体场地尺寸、目标数量、通过方式和计分细则以比赛组委会发布的正式说明为准。

## 主要功能

### 1. 图像处理与赛道提取

核心流程位于 `project/code/Image.c`、`imageUtils.c` 和 `imageElements.c`，包括：

- 图像降采样
- 白色赛道区域搜索
- 左右边界搜索
- 中线提取
- 赛道偏差计算
- 十字路口、环岛、目标区域等状态机接口

主程序在摄像头帧完成后调用 `imageProcess()`，再将视觉误差交给车体控制模块。

### 2. 运动控制

`project/code/Body_ctrl.c` 负责车体闭环控制，包含：

- 舵机位置控制
- 左右电机速度控制
- 差速与角速度辅助
- 基于编码器的速度反馈
- 定时器中断调度

`project/code/Algorithm.c` 中实现了：

- 增量式 PID
- 带速度 / 加速度前馈的电机控制
- LADRC 电机控制
- 舵机双 PD 控制
- 角速度 PID 控制
- 基于误差和误差变化率的参数调整接口

### 3. 目标识别与激光控制

`project/code/imageElements.c` 中保留了目标粗扫、目标跟踪和目标状态机逻辑，并根据目标在图像中的位置选择左、中、右激光通道。当前版本在 `imageProcess()` 中默认注释了目标状态机调用，实际参赛时需要结合现场赛道和标定参数重新启用、调试。

```text
│   ├── user/                  # main.c 与中断入口
│   └── mdk/                   # Keil C251 工程文件
└── .gitignore                 # 忽略 Keil 编译输出
```

## 编译与下载

1. 安装支持 C251 的 Keil MDK 和对应 STC32G144K 工具链。
2. 打开 `project/mdk/seekfree.uvproj`。
3. 检查工程中的库路径和硬件引脚配置。
4. 根据实际车模修改摄像头、舵机、电机、编码器、IMU 和激光器参数。
5. 编译工程并通过下载器烧录到 STC32G144K 控制板。

编译输出默认位于 `project/mdk/out_file/`。该目录已加入 `.gitignore`，不会上传 `.obj`、`.crf`、`.hex`、`.map` 等可再生成文件。

## 调试建议

- 先单独确认摄像头图像、左右边界和中线结果。
- 再进行舵机方向、编码器方向和电机极性检查。
- 低速标定 PID / LADRC 参数后，再逐步提高基础速度。
- 环岛、十字路口和目标识别状态机应分段验证，避免同时修改多个状态转换条件。
- 激光功能调试时应先确认目标坐标范围和激光通道映射，避免在目标区域外误触发。
